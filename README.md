## Project Description

This project focuses on importing data from spreadsheets using Transform Maps. It involves mapping source spreadsheet fields to the corresponding target table fields, transforming the data where necessary, and ensuring that records are imported accurately into the target system.

## Project Objectives

- Import data from spreadsheet files.
- Map source fields to the appropriate target fields.
- Transform and validate data during the import process.
- Reduce manual data entry and improve data consistency.
- Verify that imported records are correctly stored.
